## ✨ Sobre o projeto

O **Maternidade** é uma aplicação pensada para apoiar mães e responsáveis durante os primeiros momentos da vida do bebê. A proposta reúne conteúdos para quem está vivendo a maternidade pela primeira vez e recursos para acompanhar informações importantes da rotina do bebê.

## 🎯 Objetivos

- Oferecer dicas úteis para os primeiros cuidados.
- Facilitar o acompanhamento da evolução do bebê.
- Organizar informações relevantes em uma experiência simples e acessível.
- Atender diferentes telas com uma abordagem **mobile-first**.
