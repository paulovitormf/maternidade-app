# **Maternidade** 👩‍🍼🧸🍼
*Projeto em grupo desenvolvido na disciplina de Engenharia de Software II, no qual consiste em desenvolver um software. O tema escolhido foi um aplicativo de Maternidade, no qual pode-se aprender dicas de primeira viagem e realizar acompanhamento da vida do bebê, entre outras coisas.*

### **🖥️ Plataforma:** Mobile-first, desktop web 📱☁️

### **🧑‍💻 Tecnologias escolhidas:**
- **🔧 Back-end:**
    - Java + Spring Boot
- **🎨 Front-end:**
    - React + Vite
    - Tailwind CSS
    - Shadcn / Radix
- **🎲 Banco de dados:**
    - PostgreeSQL / MySQL
